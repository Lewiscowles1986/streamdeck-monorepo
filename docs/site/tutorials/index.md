# Tutorials

Learning-oriented pages: follow them start to finish. Each one gets you to a
working outcome while introducing the concepts it needs — nothing more.

1. **[From zero to a working deck](zero-to-deck.md)** — install, run the API
   + UI, create a config in the web app, assign it, run the device runner,
   and see buttons render (no hardware needed; the dummy transport emulates
   decks).

2. **[Automate with triggers](triggers.md)** — make configs switch themselves
   when an app comes to the front (macOS) or you join a Wi-Fi network.

After the tutorials, the [how-to guides](../how-to/index.md) cover individual
tasks, and the [reference](../reference/index.md) is where you look things up.
